Descrição da aplicação

O Melodia é apresentado através de uma landing page moderna e responsiva, pensada para amantes de música e jovens em busca de novas descobertas musicais. 
A página tem como objetivo apresentar os diferenciais do aplicativo e converter visitantes em leads (via cadastro de e-mail).

A página está organizada nas seguintes seções:

Hero - título de impacto, descrição do app, botões de chamada para ação e um carrossel interativo com prévias de áudio das músicas mais escutadas.
Benefícios - os principais diferenciais do app (som em alta qualidade, playlists personalizadas, descoberta de artistas, interface intuitiva), destacados com ícones.
Funcionalidades - cards apresentando as funcionalidades do aplicativo de forma visual.
Depoimentos - avaliações de usuários satisfeitos, com foto, nome e citação.
Contato - formulário para captura de e-mails para futuras campanhas de marketing.
Rodapé - informações de contato, redes sociais e links institucionais (política de privacidade, termos de uso).

Tecnologias utilizadas
HTML5 - estrutura semântica da página
CSS3 - estilizações específicas (animação das ondas de áudio, prefers-reduced-motion)
Tailwind CSS - framework CSS utilitário para o layout responsivo e o design system (cores, tipografia, espaçamentos)
Font Awesome - ícones utilizados em botões, benefícios, funcionalidades e rodapé
Google Fonts - fontes personalizadas (Space Grotesk e Manrope)
JavaScript - interações: menu mobile, cabeçalho dinâmico, carrossel de áudio, reprodução de prévias e envio do formulário de contato
